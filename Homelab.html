Planning

May 4, 2026

This is the first post for my homelab project. I wanted to have a space where I could document the process fo creating my homelab with all of the steps needed to create this lab and what I will be doing with it. The first step in this project was to find a computer that I could use for this project, unfortunately I have a limtied budget and space for this project so I need a cheap SFF pc that is powerful enough for the project or has a good upgrade path to upgrade as I go along. My budget is £80, this is a huge limitation but based on my current knowledge of the ocmputer market and some good tips from r/homelab I think this is a budget that can work. I have been looking daily on ebay and used computer websites to try and find the best PC possible for this budget. Looking thorugh r/homelab the most common starting pc other people seeem to go to is the lenovo thinkcentre M710Q tiny as it is cheap, small, power efficient and can come with a i5 6500T which woudl be a good starting point for a homelab on a budget. I will be looking for devices on used market places until I cna find one with good starting specs within my £80 budget.

The PC has finally been ordered and I managed to get a good deal on a better PC than the lenovo. i found a brilliant deal on a used SFF veryPC. It has a i3-9100T, 8gb ram and a 256gb SSD for £79.99! Restarting the project

May 17, 2026

I made a mistake but I am glad I caught it this early. The PC arrived a few days ago and I have just got round to doing the install, I decided to go with debian 13 as I had seen many people recommend debian for homelabs. Unfortunately, I did not realise that they were using debian 12 not 13 so after installing the OS and setting up all the tools I needed, I went to isntall docker. The install had many issues but I was able to install docker itself which was great. Then it came to installing docker desktop. It turns out docker desktop does not support debian 13 and it is missing crucial packages for docker desktop to function. So I have now decided to install proxmox and try again with this OS.

It is working

May 26, 2026

After rushing to install debain 12 and becoming accustomed to its differences, I stumbled across a video on hwo to install docker for debian 13. It was a simple fix that did not take much work to implement. After seeing this, I felt it was important for me to go back to debian 13, not only because it was possible to continue with docker while using a modern OS but also as a painful learning experience. I should not have given up that easily and have learnt from this that it is ok to keep looking for a solution rather than give up. So I can now happily say that I now have docker installed on the system running debian 13.
